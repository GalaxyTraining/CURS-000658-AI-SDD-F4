# Catálogos Cerrados

Un valor fuera de estos catálogos debe ser rechazado.

## 1. Categoría de producto (usado en RF-01, RF-02, RF-03, RF-05)

| Código | Descripción |
| :--- | :--- |
| `ELECTRONICS` | Electrónica y tecnología. |
| `HOME` | Hogar y decoración. |
| `FOOD` | Alimentos y bebidas. |
| `CLOTHING` | Ropa y accesorios. |
| `OFFICE` | Útiles y artículos de oficina. |
